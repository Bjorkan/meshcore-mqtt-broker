# Dashboard UI audit and remediation

## Scope

The review covered the supplied codebase and all 39 supplied dashboard captures, including desktop, mobile, dark mode, dialogs, sorting states, the MeshCore.io map, and widths from 320 to 1440 pixels.

The implementation was revised toward **Material Design 2** rather than Material 3. The visual system uses compact MD2 geometry, Roboto typography, restrained elevation, rectangular selected navigation, and the Meshat.se green identity.

## Validation performed

- `npm run check:lockfile`: passed.
- `npm run format:check`: passed.
- `npm run lint`: passed with zero warnings.
- `npm run build`: passed for the TypeScript server and ES2020 Vite dashboard. Vite retained its advisory that the main bundle exceeds 500 kB.
- `npm test`: passed all 18 suites and 220 tests.
- Focused dashboard helper, harness, and state-store tests: passed all 53 tests after the final identity, placeholder contrast, fixture, and cleanup changes.
- A fresh Docker image was seeded through the repository command using an isolated node-owned `/data` volume. The actual `/api/dashboard` payload loaded through the dashboard validator without a compatibility shim.
- The final Playwright harness passed all 61 populated, dark, mobile, breakpoint, dialog, sorting, map, pre-ready and post-ready map-failure, loading, empty, fatal-error, and refresh-warning states.
- The browser audit reported zero unexpected console errors, page errors, resource failures, horizontal overflows, duplicate IDs, unnamed controls, geometry failures, focus failures, sort-state failures, or sub-44-pixel effective coarse-pointer targets.
- Computed text and placeholder contrast passed at 4.5:1 for normal text and 3:1 for large text. The lowest audited normal-text pair measured 4.6157:1; placeholders measured at least 5.06:1, selected light navigation measured 7.1664:1, and warning chips measured at least 5.5338:1.
- Verified breakpoints included 320, 390, 600, 900, 1024, 1199, 1200, and 1600 pixels. Responsive cards remained active through 1199 pixels and desktop tables/permanent navigation activated at 1200 pixels.
- Final screenshot artifacts were generated at `/tmp/opencode/dashboard-post-ready-audit/` (61 PNG files) for human review.

## Validation limitation

Screenshot pixels were not visually interpreted and no accepted visual baseline was available for deterministic image comparison. Subjective appearance, perceived hierarchy, balance, and aesthetic polish still require human or separately configured vision-capable review; the claims above are based on source, DOM, accessibility, computed styles, contrast calculations, geometry, overflow, keyboard behavior, and browser diagnostics.
